Security and runtime behavior that affects the website

BoundarySourceBehavior
Cookiesrc/server/auth.ts lines 11-12, 177-187rcp_session, seven-day expiry, random token stored only in browser cookie, SHA-256 token hash stored in DB, HttpOnly, SameSite=Strict, secure in production.
Passwordsrc/server/passwords.ts lines 1-29Scrypt hash format; login verifies without storing plaintext password.
CSRF-style origin checksrc/server/http.ts lines 25-34Mutating API routes reject requests whose Origin header does not match the request URL origin.

Private profilessrc/server/profile.ts lines 274-280Private or inactive profiles are hidden except to owner/admin; private contact data is hidden except to owner/admin.

Deployment path

  • SOURCEGitHub repository

    Main branch contains Next.js app source, database scripts, tests, and assets.

  • BUILDVercel

    Runs the Next build and hosts Node server functions for API routes and server-rendered pages.

  • RUNTIMEOracle Cloud

    The app connects as RCP_APP through environment variables and wallet configuration.

  • EXTERNALOpenAlex

    Server-only publication metadata source for DOI and author imports.

Code deployment and schema deployment are separate. Pushing the Next app updates Vercel; changing tables, triggers, packages, or grants requires running the SQL scripts deliberately against Oracle.
