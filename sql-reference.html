APPENDIX A / SQL reference

Appendix A · All SQL

Every SQL entry point in the project.

This appendix is the map for every SQL statement in RCP: schema DDL, seed DML, views, packages, triggers, grants, test SQL, setup SQL, cleanup SQL, and SQL embedded in the TypeScript backend. The canonical full text stays in the source repo; this page tells you exactly where each statement group lives, what category it belongs to, and what objects it touches.

SQL execution order

The local database harness rebuilds the schema in this exact order. Anything that depends on a previous object must come later: views after tables, grants after packages/views, tests after everything.

Destructive boundary

00_reset.sql drops packages, views, triggers, tables, constraints, columns, indexes, and the sequence. It is for rebuilds, not production migrations with live data.

Mutation patterns used by the backend

PatternExampleWhy it matters
INSERT ... RETURNING ... INTOauth.ts lines 76-80; publications.ts lines 142-145; posts.ts lines 71-72.Oracle returns the generated ID in the same round trip so the transaction can insert child rows immediately.
SELECT ... FOR UPDATEapplications.ts lines 34 and 59; connections.ts lines 47, 61, 72; publications.ts lines 127-128; posts.ts line 60.Locks the row while checking ownership/status, preventing two requests from changing the same workflow state inconsistently.
Delete-and-reinsert child rowsposts.ts lines 47-54; profile.ts lines 387-412; publications.ts lines 182-185.Simple replacement for many-to-many sets: delete the old set, insert the submitted set, all inside one transaction.
Soft delete / deactivationpublications.ts lines 196-203; admin.ts lines 19-22.Records are hidden by status instead of physically deleted, preserving relationships and auditability.
Named bindsEvery runtime query uses :name binds.Equivalent to JDBC PreparedStatement; user input is never concatenated into SQL text as a value.
Dynamic placeholder listposts.ts lines 40 and 44; profile.ts lines 343-355 and 361.Only placeholder names are generated from array indexes; actual values still pass as binds.
Package call through ref cursorsearch.ts lines 127-150.Lets Oracle own complex search predicates while TypeScript only passes validated filters.
